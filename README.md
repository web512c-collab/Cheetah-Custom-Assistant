# Cheetah Custom Assistant (Android)

**Cheetah Custom Assistant** is a 100% self-contained, zero-external-API native Android personal assistant (`minSdk 24` / Android 7.0+, `targetSdk 36`, Kotlin + Jetpack Compose) built natively for **Egyptian Colloquial Arabic (العامية المصرية)**.

### Key Capabilities
- **Zero External APIs:** Runs completely offline on-device with no Gemini/OpenAI API keys and no `INTERNET` permission in `AndroidManifest.xml`.
- **Bundled Offline Acoustic Model ('يا شيتا') + MFCC-DTW Wake Service:** `WakeWordDetectionService` (`FOREGROUND_SERVICE_TYPE_MICROPHONE`) loads the bundled Int8 binary keyword-spotting model (`assets/models/cheetah_ya_sheeta_kws.bin`, `CHKW` v1 format, generated by `scripts/generate_ya_sheeta_model.py` and memory-mapped via `MappedByteBuffer`) to monitor 16kHz PCM audio continuously for Egyptian Arabic **`يا شيتا`** out of the box, combined with user-enrolled MFCC-DTW templates & Voice Match speaker verification (`AudioFeatureExtractor` + `WakeWordEngine`). Upon wake detection, it pauses `AudioRecord`, speaks the configurable Egyptian acknowledgment (*"أيوه، معاك"*), runs Main-Looper offline `ar-EG` STT, executes the command, speaks the Egyptian TTS reply, and automatically resumes wake-word listening—even with the screen off or UI closed.
- **System Digital Assistant Registration:** Implements `VoiceInteractionService`, `VoiceInteractionSessionService`, `VoiceInteractionSession`, `RecognitionService`, `BootCompletedReceiver` (API 24–33 auto-start + API 34+ compliant resume notification), and `ACTION_ASSIST` / `ACTION_VOICE_COMMAND`.
- **Egyptian Colloquial Arabic NLU, Memory & J.A.R.V.I.S. Guardrails:** Local dialect parser with contextual follow-ups (`ActiveAppContext`), personal shortcuts (`ConversationMemoryStore`), compound commands, 3 Egyptian personas, and deterministic **Hard End-Line** security guardrails (`CommandGuardrailValidator`).
- **16-Point Settings & Wake Diagnostic Console:** Default Assistant setup, voice/text custom wake name, sensitivity & Voice Match controls, customizable wake acknowledgment phrase, local STT/TTS offline-voice telemetry, live 12-field Wake-Word Diagnostic Console, and Local Memory & Shortcuts inspector.

## Building Locally

### Prerequisites
- **JDK 17** (or JDK 21)
- **Android SDK** with `platforms;android-36.1` and `build-tools;36.0.0`

### Commands
```bash
# Make wrapper executable (Linux/macOS)
chmod +x gradlew

# Run core JVM unit tests
./gradlew :app:testDebugUnitTest --tests "com.example.CheetahCoreUnitTest" --tests "com.example.ExampleUnitTest"

# Build Debug APK
./gradlew assembleDebug
```
The Debug APK is output to:
`app/build/outputs/apk/debug/app-debug.apk`

## Verification & Compatibility Matrix

| Check Type | Scope | Status |
|---|---|---|
| **JVM Unit Tests** | `CheetahCoreUnitTest` (MFCC-DTW, NLU context/shortcuts/compounds, Guardrails, Phonetic folding, TTS normalization) & `ExampleUnitTest` | Passed via Gradle |
| **Debug APK Build** | `compile_applet` & `assembleDebug` | Passed via Gradle |
| **Robolectric / Instrumented / Hardware** | `ExampleRobolectricTest` (requires Maven artifact network access), real mic/AudioRecord, OEM `SpeechRecognizer` offline `ar-EG` pack, physical screen-off wake loop | Requires online CI runner or physical Android device |

- **Android 7.0–9.0 (API 24–28):** Standard `startForeground`, `AudioRecord` pause/resume handoff before `SpeechRecognizer`, `Settings.ACTION_VOICE_INPUT_SETTINGS`.
- **Android 10–13 (API 29–33):** `RoleManager.ROLE_ASSISTANT`, `FOREGROUND_SERVICE_TYPE_MICROPHONE`, service-owned post-wake STT/TTS loop (immune to background activity launch blocks).
- **Android 14–16 (API 34–36):** `BootCompletedReceiver` posts compliant one-tap resume notification instead of illegal background microphone FGS launch from `BOOT_COMPLETED`.

## GitHub Actions CI/CD (`.github/workflows/android-build.yml`)

1. Uses **JDK 17 (Temurin)** and the runner's preinstalled Android SDK (`sdkmanager` installs `platform-tools`, `platforms;android-36.1`, `build-tools;36.0.0`).
2. Runs core unit tests (`CheetahCoreUnitTest`, `ExampleUnitTest`), runs `ExampleRobolectricTest` (non-blocking), and builds `assembleDebug`.
3. Uploads **`cheetah-debug-apk`** (`app/build/outputs/apk/debug/*.apk`), optionally builds signed release if keystore secrets are configured, and publishes GitHub Releases on `v*` tags.
